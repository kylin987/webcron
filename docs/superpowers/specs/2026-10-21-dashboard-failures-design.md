# 概况性能与失败可见性

用户已确认站内提醒方案。最近执行结果按日志 ID（完成写入顺序）持久化到任务，未执行以 last_log_id=0 表示；失败与超时均属于当前失败，后续成功自动解除。任务结果不随日志清理消失，日志详情可能已被清理。共享可见性沿用现有任务权限。

概况最近日志仅取20条摘要，不统计总数；联表获取任务名，失败按状态分别利用索引取前20后合并。跳过系统级 cron 条目，避免类型断言 panic。任务列表从任务表读取最近结果，支持组合失败筛选。顶部每30秒顺序轮询轻量失败摘要接口，后台页面暂停轮询；请求失败显示不可用而非零失败。现有失败邮件条件覆盖超时。

新增任务结果字段、日志状态/ID索引及任务状态索引；提供存量日志最新结果回填脚本。不发布、不更改现有数据库配置，不触发真实任务。使用隔离 MySQL 验证查询、状态迁移和回填，以及 Go 测试和浏览器模拟数据检查。
